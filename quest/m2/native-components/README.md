# Native component composition

## Goal

The extension controls compose into a small settings and information example without duplicated ownership, event dispatch or visual contracts.

## Plan

This epic owns the final combined example and affected integration check once its children are complete. Exercise form relationships, a bounded content region, independent action areas, overlay focus and state preservation. Reuse accepted component evidence. Keep examples generic and free of application networking/media/session data. Do not list child quests here or introduce a second renderer or global form state manager.
