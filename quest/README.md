# Quests

## Goal

Build an independent, shadcn-inspired egui component library with shared native
and WebAssembly examples, explicit interaction contracts, and reproducible checks.

## Plan

M0 establishes the workspace, semantic theme tokens, and acceptance gallery.
M1 delivers core components and the first Pages gallery, beginning with Button
and Input. M2 expands complex components and platform validation from concrete
requirements. A planning PR will introduce the milestone and component quests
after the initial repository baseline exists.
