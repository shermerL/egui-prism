# Quests

## Goal

Build an independent, egui component library with strict shadcn parity with shared native
and WebAssembly examples, explicit interaction contracts, and reproducible checks.

## Required

- [M0: Engineering, theme, and acceptance foundations](/quest/m0/README.md)
- [M1: Core components and first Pages gallery](/quest/m1/README.md)
- [M2: Complex components and platform completeness](/quest/m2/README.md)

All milestones and components follow [the shadcn parity contract](/docs/shadcn-parity.md).
