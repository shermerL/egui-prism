# Quests

## Goal

Build an independent egui component library with strict shadcn parity for native
macOS, Windows and Linux, explicit interaction contracts, and reproducible checks.
Browser delivery is a separate, deferred product decision.

## Required

- [M0: Engineering, theme, and acceptance foundations](/quest/m0/README.md)
- [M1: Core components and native gallery](/quest/m1/README.md)
- [M2: Complex components and platform completeness](/quest/m2/README.md)

All milestones and components follow [the shadcn parity contract](/docs/shadcn-parity.md).
